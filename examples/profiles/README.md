# Example Soul Profiles

`Thorn/SKILL.md` is a fictional, non-personal example of the document Soulforge
materializes for every forged companion. The character name is the visible
folder; the fake numeric AzerothCore ID remains internal identity metadata.

Run `scripts/validate-skill-inference.py` while the configured Ollama model is
available to prove that the actual inference worker uses Thorn's owner-editable
character section.
