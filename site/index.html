BEFORE YOU BEGIN

What you need

Soulforge brings its application dependencies in containers. Your host only needs a small foundation.

Linux

A Linux host

x86_64 or ARM64 with a stable connection to your home Wi-Fi or Ethernet.

6+

Memory and disk

At least 6 GiB RAM and 15 GiB free. Larger models need more of both.

3.3.5a

Your own WoW client

A legally obtained build 12340 client. Game software and Blizzard assets are not included.

LAN

A trusted network

No router port-forwarding. This alpha is not designed for public internet exposure.

Host tools: Docker Engine, Docker Compose v2, Git, Make, OpenSSL, curl, Python 3.8+, and iproute2. The first command below verifies them.

SET UP THE HOST

From clone to running realm

Work through these steps on the Linux computer that will host the server.

1

Clone the public repository

Choose a permanent directory. Runtime data and model weights are excluded from Git.

git clone https://github.com/ryanbieber/azeroth-soulforge.git
cd azeroth-soulforge
cp .env.example .env
2

Set private credentials and your LAN address

Run ip -brief address. Find the stable address belonging to your real Wi-Fi/Ethernet interface, then edit .env.

DB_ROOT_PASSWORDLong, unique database password
BRIDGE_SECRETLong event-bridge secret
CONTROL_SECRETDifferent secret, at least 32 characters
ADMIN_PASSWORDDashboard password, at least 12 characters
SOULFORGE_SECRETS_KEYUnique key that encrypts provider credentials at rest
GAME_USERNAME / PASSWORDYour private WoW login
LAN_IP / BIND_ADDRESS / LAN_CIDRYour host address and trusted subnet

Use the full SOULFORGE_ names shown in .env.example. Never commit .env or post it in an issue.

3

Check the host and allow LAN traffic

The firewall rule permits authentication, world, and dashboard traffic only from your configured subnet.

make doctor
make firewall

make firewall asks for the Linux administrator password. Ollama, MySQL, Soul Service, and the internal control agent remain unavailable to the LAN.

4

Start the complete application

The first start compiles AzerothCore, imports databases and map data, downloads the roughly 1.4 GB ambient-chat model, and prewarms durable Playerbot state before opening login. Without a paid AI key it also downloads the larger companion/director model. It may take several minutes. Later starts reuse the prepared data and bots wait for the human before joining.

make up

Wait for Azeroth Soulforge is ready. Use make status or make logs in another terminal to watch progress.

CONNECT

Dashboard and game client

CONTROL PLANE

Open the dashboard

From a trusted device on the same LAN. The first screen asks for a world prompt, faction, and your dungeon role. Everyday controls stay focused on forging, entering, companions, world history, and AI:

https://YOUR_LAN_IP:8765

Verify the private address, accept the expected self-signed certificate, and sign in with SOULFORGE_ADMIN_PASSWORD. Advanced → Experience provides bounded 0.1×–10× XP scaling; applying it restarts worldserver without changing existing levels or progression limits.

WOW 3.3.5a CLIENT

Point the client at your realm

Edit the locale file, such as Data/enUS/realmlist.wtf:

set realmlist YOUR_LAN_IP

Start Wow.exe directly and use the game credentials in your private .env.

AI AND CONTINUITY

Choose the mind. Keep memory under control.

AI STUDIO

Deep companions, local realm chatter

Use local Ollama, OpenAI, Anthropic, Gemini, or an OpenAI-compatible service. Ambient AI stays local through /say, General, and LocalDefense; Trade remains shared across trade-enabled cities, while World and LFG are ignored. Fresh worlds default to a 25% chance and five-second cooldown.

BOUNDED MEMORY

Meaning, not endless transcripts

Each companion keeps 60 recent messages. World chat enters a 12-exchange temporary buffer; after eight exchanges, only durable relationships, promises, discoveries, and decisions are distilled into the Chronicle. Ambient population replies do not receive or create deep personal memories.

LEAD YOUR GROUP

Soulforge inside ConsolePort

The authenticated local dashboard provides one pack with pinned ConsolePortLK, Soulforge Commander, and legacy Windows WoWmapperX. Copy only the addon folders into Interface/AddOns, start Controller\WoWmapperX\WoWmapperX.exe, then launch WoW. Commander automatically uses ConsolePort's default utility-ring chord on the bar without replacing movement controls.

Hold both modifiers plus the lower face button to open Commander, then choose Companions to sync the active world, select command targets, and Assemble enabled companions. Names update without another download. WoWmapperX is archived/deprecated upstream, is never launched automatically, and is included only in the authenticated local pack; this public website does not host client binaries. Commands remain user-initiated Playerbots chat orders. Complete setup →

TROUBLESHOOTING

When something cannot connect

Inspect the stack

make status
make logs
ss -ltn | grep -E ':3724|:8085|:8765'

Check the network

  • Server and client use the same non-guest LAN.
  • Wi-Fi client isolation is disabled.
  • The configured IP belongs to the host.
  • The trusted CIDR contains the client IP.
  • realmlist.wtf has no URL scheme or port.

A fresh large Playerbot population takes time to prepare. The first make up caches bot characters in a maintenance world before opening login; later starts reuse that state and begin conservative bot batches only after the human connects. Run make bots separately only while game services are stopped.
