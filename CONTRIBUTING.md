# Contributing

Thank you for helping build Azeroth Soulforge.

1. Read `AGENTS.md` and `docs/PROJECT.md`.
2. Open an issue before a large architectural or contract change.
3. Keep changes within the project's gameplay/social-layer boundary.
4. Add tests and update the durable specification when behavior changes.
5. Run `./scripts/verify.sh` before opening a pull request.

Do not submit proprietary game data, private conversations, secrets, model
weights, or generated databases. By contributing, you agree that your
contribution is licensed under GPL-2.0-only.
